# Rate–Distortion Scaling Laws for Language Models

Repository accompanying the manuscript *"A Rate–Distortion Framework for
Language-Model Scaling Laws: Entropy Floor, Two-Bottleneck Exponents, and the
Joint Law"* (submitted to *Entropy*).

Everything needed to reproduce the empirical validation is here: pre-registered
protocol, experiment and analysis scripts, figure scripts, and committed result
artifacts. Heavy corpora and model weights are **not** stored; they are
downloaded/generated by the scripts.

## Layout

```
manuscript/            LaTeX source for the paper (main_entropy.tex) and
                       supporting information (supporting_information.tex)
anon/                  Clean, self-contained companion release with its own
                       README and the pre-registered protocol (authorship-safe)
experiments/           Experiment code
  pythia/                Task 1: alpha_N sweep on the Pythia ladder (70M-2.8B)
  empirical/             Task 2: alpha_D identifiability (fixed-E profile)
  corpus_statistics/     spectral findings (markdown)
  prediction_validation/ P39 single-domain control (train_p39.py, findings)
  synthetic/             synthetic-control (known power-law) experiments
scripts/               Analysis, figure-generation, and conversion scripts
results/               Committed results: figures, evidence matrix, statistics,
                       tables, raw npz arrays, validation index (README_validation.md)
```

## Headline empirical results (honest summary)

The theory gives closed-form exponents
`alpha_N = gamma(2s/beta_reg - 1)` and `alpha_D = gamma_ent/(2 beta_corr)`.
The empirical audit reports the components that are supported, contradicted,
unresolved, or measurement-confounded:

- A4 spectral-capacity and channel-smoothness assumptions: **NOT SUPPORTED**
  (measurement-confounded — the window-covariance estimator fails to recover
  known power-law structure even on synthetic controls).
- alpha_N prediction: **PARTIALLY SUPPORTED** on prose; **CONTRADICTED** on code.
- Prediction 39 (boundary-degeneracy ordering): **CONTRADICTED** — the
  pre-registered ladder test found code decays *faster* than prose.
- alpha_D: **NOT TESTED** (gamma_ent unresolvable with current plug-in
  estimators).
- Entropy-floor identification, the recovery structure, and the joint law are
  exact and unaffected by the pre-registered test outcome.

The full claim-by-claim status is in `results/evidence_matrix.csv` and
`results/README_validation.md`.

## Reproduce

See `anon/README.md` for the self-contained reproduction walkthrough
(environments, commands, runtime estimates), and
`results/README_validation.md` for the script-to-output mapping and exact
reproduction commands.

Environment: Python 3.10+, numpy, torch (CUDA), transformers, pandas, pyarrow,
huggingface_hub.

## Data

- Raw corpora (external, downloaded by scripts): wikitext-103-raw and
  github-code (see `anon/pythia/build_corpora.py`).
- Committed derived data: token/entropy statistics, window-loss arrays, and
  `.npz` run artifacts (see `results/` and `experiments/`).
